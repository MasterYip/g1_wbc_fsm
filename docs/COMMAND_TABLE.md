# G1 机器人手柄指令与状态切换表

> 打印版本 | 生成日期: 2026-07-08

---

## 一、按键组合 → 指令

| 按键组合 | UserCommand | 功能 |
|:--------:|:-----------:|------|
| **Start** | START | 进入固定站立模式 |
| **Select** | SELECT | 退出程序 |
| **L2 + B** | L2_B | 进入被动模式 (全局可用) |
| **R2 + A** | R2_A | 进入 MJAMP / Loco 模式 |
| **R2 + B** | R2_B | 从 AMP/MJAMP 返回 Loco |
| **R1 + ↑** | R1_UP | 进入 WBC 动作模仿模式 |
| **R1 + ←** | R1_LEFT | WBC left (预留) |
| **R1 + →** | R1_RIGHT | WBC right (预留) |
| **R2** | R2 | WBC 暂停 (预设参考帧) |
| **L2** | L2 | WBC 暂停 (当前参考帧) |
| **R1** | R1 | WBC 继续播放 |
| **R2 + ↑** | R2_UP | AMP/MJAMP 高速模式 |
| **R2 + ↓** | R2_DOWN | AMP/MJAMP 低速模式 |

---

## 二、摇杆 → 运动控制

| 摇杆轴 | 控制方向 | 生效状态 |
|:------:|:--------:|:--------:|
| 左摇杆 **↑↓** | 前进 / 后退 | Loco / AMP / MJAMP |
| 左摇杆 **←→** | 横向平移 | Loco / AMP / MJAMP |
| 右摇杆 **←→** | 原地转向 | Loco / AMP / MJAMP |

---

## 三、FSM 状态列表

| 状态 | 说明 |
|:----:|------|
| PASSIVE | 被动阻尼模式 (初始状态) |
| FIXEDSTAND | 固定站立 (位置控制) |
| LOCO | RL 强化学习行走 |
| WBC | 全身控制 / 动作模仿 |
| MJAMP | MuJoCo 对抗运动策略 (默认) |
| AMP | 对抗运动策略 |

---

## 四、状态切换表

| 当前状态 | 按键 | 目标状态 |
|:--------:|:----:|:--------:|
| PASSIVE | Start | FIXEDSTAND |
| PASSIVE | Select | 退出程序 |
| FIXEDSTAND | L2 + B | PASSIVE |
| FIXEDSTAND | R2 + A | MJAMP |
| FIXEDSTAND | Select | 退出程序 |
| LOCO | L2 + B | PASSIVE |
| LOCO | R2 + A | MJAMP |
| LOCO | R1 + ↑ | WBC |
| LOCO | Select | 退出程序 |
| WBC | L2 + B | PASSIVE |
| WBC | R2 (运行时) | WBC 暂停 |
| WBC | L2 (运行时) | WBC 暂停 |
| WBC | R1 (暂停中) | WBC 继续 |
| WBC | R2 + A | AMP |
| WBC | Select | 退出程序 |
| AMP | L2 + B | PASSIVE |
| AMP | R1 + ↑ | WBC |
| AMP | R2 + ↑ | AMP 高速 |
| AMP | R2 + ↓ | AMP 低速 |
| AMP | R2 + B | LOCO |
| AMP | Select | 退出程序 |
| MJAMP | L2 + B | PASSIVE |
| MJAMP | R1 + ↑ | WBC |
| MJAMP | R2 + ↑ | MJAMP 高速 |
| MJAMP | R2 + ↓ | MJAMP 低速 |
| MJAMP | R2 + B | LOCO |
| MJAMP | Select | 退出程序 |

> 任何状态下 **姿态异常** 自动退回 PASSIVE (安全保护)
